# Secure Server Git Network Automation

## Project Overview

This project demonstrates Linux server administration,
network troubleshooting, and automation using Bash and Python.

It includes scripts for monitoring system health, checking
network connectivity, analyzing logs, auditing user accounts,
and verifying backup archives.

## Objectives

- Automate routine Linux administration tasks.
- Monitor system health and service availability.
- Diagnose common networking problems.
- Analyze log files to identify errors and warnings.
- Verify backup archives.
- Audit local user accounts.
- Track project changes using Git and GitHub.

## Technologies Used

- Linux
- Bash scripting
- Python 3
- Git and GitHub
- Networking fundamentals
- Nginx
- Linux system logs
